# 参数依据：`params_hydraulic_arm.m`

## 1. 设计边界

- 构型：6 自由度串联机械臂，6 个关节均采用阀控液压摆动马达。
- 臂展设计口径：约 1.6 m，测量端点待确认。按下表，基座原点到 `link_6` 原点的逐段偏移长度之和为 1.33 m，这是该段直线距离的几何上界。夹爪或工具尖端需另外定义。
- 额定负载：30 kg，挂接在末端连杆；后续如需切换 3050 kg，请通过 `payload_mass` 与 `payload_com` 重新校核。
- 本文件记录的是仿真端参数；现场调试只允许通过 `edge_config.yaml` 的 `max_torque` 与 `torque_overload_threshold` 调整保护阈值，不允许直接改控制律。

## 2. 运动学

| 关节 | a / m | alpha / rad | d / m | 说明 |
|---|---:|---:|---:|---|
| J1 | 0.00 | pi/2 | 0.18 | 腰部回转 |
| J2 | 0.50 | 0 | 0.00 | 大臂俯仰 |
| J3 | 0.45 | 0 | 0.00 | 小臂俯仰 |
| J4 | 0.00 | pi/2 | 0.12 | 腕部回转 |
| J5 | 0.00 | -pi/2 | 0.00 | 腕部摆动 |
| J6 | 0.00 | 0 | 0.08 | 末端安装距离 |

上表按标准 DH 写法给出。J1 的连杆质心放在回转轴线上，避免把腰部结构偏心错误地折算成绕 J1 的重力矩。

## 3. 质量、惯量与摩擦

- 连杆质量为结构估算值，单位 kg；转动惯量为绕连杆质心的对角张量，单位 kg·m²。
- 摆动马达转子惯量按 `Jm * a*a'` 叠加到对应连杆惯量，`a` 为该关节轴在连杆坐标系中的方向。
- 摩擦采用黏性 + 库仑 + Stribeck 模型，统一用 `tanh(qd/eps)` 平滑，避免零速开关摩擦导致的数值抖动。
- 末端负载在 RNEA 中参与合成后的末端质心与惯量，而不是只把质量点硬加到最后一个关节。

## 4. 液压系统

### 4.1 压力等级

- 供油压力：25 MPa。
- 回油压力：1 MPa。
- 依据 GB/T 2346-2003 的流体传动系统及元件公称压力系列，25 MPa 属于常用高压液压系统等级。

### 4.2 摆动马达排量

排量表为 cm³/rev：

| J1 | J2 | J3 | J4 | J5 | J6 |
|---:|---:|---:|---:|---:|---:|
| 250 | 400 | 160 | 50 | 40 | 30 |

排量选择参照 GB/T 2348-2018 的缸径/液压元件规格系列思路，按关节负载量级分档：J1/J3/J5/J6 用较小排量，J2 保留最大力矩储备。仿真中所有力矩上限均由此排量直接推出：

`T_max = (P_s - P_r) * Dm`

Dm 为弧度制排量，单位 m³/rad。

### 4.3 腔室容积

单腔等效容积：

`V = V_hose + k_vd * Dm_cm3_per_rad`

当前取：

- `V_hose = 15 cm³`，表示单腔管路、阀块和死区容积；
- `k_vd = 2`，对应约 2 rad 行程的腔体容积；
- 腔室容积不再使用统一的 1.2e-4 m³，否则对小排量腕部马达相当于多圈无效容积，会错误降低液压固有频率。

### 4.4 油液弹性模量与泄漏

- 有效体积弹性模量：1.0 GPa。该值对应约 1% 含气量的工程常用取值。
- 总泄漏/阻尼系数：1e-12 m³/(s·Pa)。先前使用 6e-12 会把额定流量对应成约 46% 的泄漏，显然不物理；修正后约为额定工况的 6%。

## 5. 控制器标定值

| 项 | 数值 | 说明 |
|---|---:|---|
| 闭环带宽上限 | 12 rad/s | 不直接追高，避免激励液压谐振 |
| 液压阻尼极点比例 | 0.25 | `wc <= 0.25 * 2*beta*Ct/V` |
| 期望阻尼比 | 0.9 | 用于 PID 与 ANNC 的 Kd、Lambda |
| RBF 中心数 | 边端 64 / 整定 256 | 64 用于对照边端默认 |
| RBF 学习率 | 边端 0.1 / 整定 200 | 按真实惯量和作业幅值整定 |
| RBF 核宽 | 边端 0.0884 / 整定 0.60 | 修正 12 维输入下激活不足 |
| 位置归一化 | 按实际作业幅度 | 不再使用固定 pi/2，避免轨迹挤在角落 |
| 速度归一化 | 按五次多项式峰值 | 与参考轨迹量级一致 |

边端配置中 `max_torque=50 N·m`、`torque_overload_threshold=40 N·m` 目前只是通用保护值，明显低于机械臂真实液压能力。仿真端完成后，应只把这两个阈值替换为按关节能力折算的安全边界，控制律参数保持同步审查。
