# V2.0 交付材料骨架（组 C 统筹）

- 用途：定结构、定口径，数字留占位，等 B 的实验数据填入
- 关联：`docs/v2-summary.md`（工程汇总）、`docs/member-c-onboarding-walkthrough.md`（复现走查）
- 原则：每个数字必须能回指 `run_id` 或原始文件路径；所有性能结论标注仿真条件

## 1. 演示录屏分镜（目标 4 分钟）

| 幕 | 时长 | 画面 | 操作 | 解说要点 |
|---|---|---|---|---|
| 1 | 0:00–0:30 | 标题页 | 无 | 实验名称、仿真条件、Python plant、非工业实测 |
| 2 | 0:30–1:30 | 架构图 | 指向数据流图 | 端→边→云：滤波/检测/容错/决策 → MQTT → 入库 → 页面 |
| 3 | 1:30–2:30 | 终端 | `py -B test/experiments/live_decision_demo.py` | 注入 J0 卡滞 → FAULT → DECISION → 优雅退出 |
| 4 | 2:30–3:30 | 浏览器 | 登录 → 实验回放 → 打开 `run_id` | 事件时间线、曲线、导出按钮 |
| 5 | 3:30–4:00 | 边界页 | 无 | 实时 Run 为部分记录；ROS 2 链路未验证 |

录制要点：终端字号调大、隐藏敏感信息（`.env`、证书口令）、片尾保留 `run_id` 字幕。

## 5. 数字复核检查表（每条结论逐项打勾）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 结论有 `run_id` | 每个统计量可定位到 Run 或汇总文件 |
| 2 | 场景条件完整 | 关节、注入时刻、容差、种子齐全 |
| 3 | 仿真条件标注 | 写明 Python plant、控制频率、合成力矩 12.5 N·m |
| 4 | 分母说清 | 成功率注明样本数与分母（24 场景或子集） |
| 5 | 失败不隐藏 | 失败案例单列，不并入成功 |
| 6 | 停止与恢复分开 | 安全停止不得计入恢复成功 |
| 7 | 数字与图表一致 | 图表数据点可回指原始汇总 |
| 8 | 无越界表述 | 不声称工业现场实测或普适比例 |
