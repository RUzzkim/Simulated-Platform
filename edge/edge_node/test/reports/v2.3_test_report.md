## 1. 被测功能

### 1.1 多轴同步梯形速度轨迹规划（新增 `TrapezoidPlan` 类）
- 所有关节共享同一归一化位移 profile s(t)∈[0,1]，按最大关节位移 d_max 归一，速度按位移比例分配，全部关节**同时启停**（工业标准点到点运动生成）。
- d_max ≥ v_max²/a 时为梯形（加速-匀速-减速）；否则自动退化为三角形（v_peak = √(a·d_max)，无匀速段）。
- `MOVE_JOINT` / `MOVE_HOME` 从当前位置实时重规划；`STOP` 清除规划、保留 Kd 阻尼刹车语义。
- 替代 v2 阶跃目标，消除速度/力矩冲击。CLI：`--traj {step,trapezoid}`（默认 trapezoid）、`--plan-vmax 1.0`、`--plan-acc 2.0`。

### 1.2 科氏/离心项 C(q,q̇)·q̇
- 与 M(q) 同源的 Lagrangian 一致形式：动能交叉项 c_k·cos(q_k-q_{k+1})·q̇_k·q̇_{k+1} 经 Lagrange 方程求导得
  - `τ_c[k] += c_k·sin(q_k-q_{k+1})·q̇_{k+1}²`
  - `τ_c[k+1] -= c_k·sin(q_k-q_{k+1})·q̇_k²`
- 与 M(q) 非对角项共用同一组耦合系数 `--coupling`，运动方程升级为
  `M(q)·q̈ = τ_motor - τ_g - τ_f - C(q,q̇)·q̇`
- CLI：`--coriolis/--no-coriolis`（默认启用）。

## 3. 测试 2：科氏/离心项（2/2 PASS）

**配置**：`--home 0.3,0.4,0.2,0,0,0 --coupling 0.1,0.3,0.05,0.03,0.02 --plan-vmax 4.0 --plan-acc 8.0 --v-limit 5.0`，目标 `[5.2, 3.2, 1.8, 0, 0, 0]`（梯形，T=1.73s，巡航段 qd0=4.0 持续约 0.7s）。科氏 ON / OFF 各运行一次。

**观测方案说明**：匀速巡航段 q̈=0，科氏力矩被 PD 伺服 1:1 补偿进电机力矩（effort 上报），因此 `τ_motor,ON - τ_motor,OFF ≈ C(q,q̇)q̇` —— 该签名不受高增益位置环压制，是科氏力的直接物理证据。

| # | 用例 | 判据 | 实测 | 结果 |
|---|---|---|---|---|
| 2a | 科氏力矩签名 | 巡航段最大力矩差 > 0.15 N·m（理论量级 ~1） | **1.4900 N·m**（73 个巡航对齐采样，qd0≈3.94 rad/s） | PASS |
| 2b | 双向收敛且有界 | 终端误差 < 0.05 且全程 \|q\| < 6.5 | ON 误差 [0.0013, 0.0012, 0.0010]，OFF [0.0013, 0.0013, 0.0011]，有界 | PASS |

信息项（非判据）：对齐后位置轨迹残差 0.0256 rad —— 科氏力确实改变轨迹形状，但被 Kp=50 高增益伺服部分抑制。

### 调参过程记录（两轮实验）
1. **第一轮**（短行程 `[1.5,1.0,0.5]`，三角形规划 v_peak=3.10）：位置轨迹残差仅 0.0093 rad，低于阈值 —— 定位到根因：**高增益 PD 伺服强力抑制科氏扰动的位置偏差**（准静态偏差 ≈ τ_c/Kp），属正常闭环行为而非实现错误。
2. **第二轮**（长行程产生持续匀速巡航段，改用力矩差签名）：1.49 N·m，与理论 ~1 N·m 量级吻合，PASS。对齐方式为运动起点锚定 + 最优平移搜索（±8 采样），消除指令到达时序抖动影响。

## 10. 云端侧四链路全链路联调（真实 Java 云端复测 8/8 PASS，2026-09-19）

## 11. 容错纯 MQTT 执行器闭环（8/8 PASS，2026-09-19）

## 12. 边端信号滤波与离群点剔除模块（单元 13/13 + 链路回归 12/12 PASS，2026-09-19）
